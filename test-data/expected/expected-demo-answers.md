# Expected Demo Answers

## 概要

本ファイルはサービス資産化エージェントの4つのデモ質問に対する期待応答の要点を記述します。
実際のエージェント応答が以下の要件を充たしているかを確認するために使用します。

---

## 質問1: 全体傾向

**質問**: 複数案件に共通して発生している課題、要件、リスクを、出現件数と根拠案件付きで整理してください。

### 期待される応答の要件

- [ ] 3つのパターン（API Modernization・AI Agent Production・AI-ready Data Foundation）が識別される
- [ ] 各パターンに4案件が含まれる（P001/P003/P006/P011、P002/P004/P008/P010、P005/P007/P009/P012）
- [ ] Fabric Data Agentを使用して件数・出現率を集計している
- [ ] Azure AI Searchを使用して背景・教訓を補足している
- [ ] ProjectIDが根拠として明示されている
- [ ] 文書タイトル（例: P005 Retrospective）が引用されている
- [ ] DraftデータやLost案件のProjected Outcomeが共通パターンとして誤引用されていない

### 期待される数値

- API Modernization共通要件: 6件（4案件中3件以上）
- AI Agent Production共通要件: 6件（4案件中3件以上）
- AI-ready Data Foundation共通要件: 6件（4案件全4件）

## 質問2: サービス候補

**質問**: 受注率、利益率、工数削減効果、案件間の共通性を踏まえ、最も再利用性が高い標準サービス候補を1つ提案してください。

### 期待される最有力候補

**AI-ready Data Foundation Service**

### 期待される根拠（必須）

- [ ] 対象案件: P005、P007、P009、P012 が明示されている
- [ ] 受注数: 4件中4件（受注率100%）が示されている
- [ ] 平均利益率: 約32.0% が示されている
- [ ] 平均工数削減率: 約35.8% が示されている
- [ ] 受注案件売上合計: 2,190百万円 が示されている
- [ ] 受注案件利益合計: 700百万円 が示されている
- [ ] 共通要件（統合データモデル・データ品質・リネージ・Semantic Model・準リアルタイム・RBAC）が列挙されている
- [ ] Fabric Data Agentから数値を取得している
- [ ] Azure AI Searchから文書根拠（Retrospective等）を取得している
- [ ] totalWonProfitJPYMillion と lostBidCostJPYMillion を混在させていない

### 比較データ（他パターンより優位である根拠）

| パターン | 受注率 | 平均利益率 | 売上合計 |
|---|---:|---:|---:|
| API Modernization | 75.0% | 28.3% | 1,500百万円 |
| AI Agent Production | 75.0% | 22.9% | 1,090百万円 |
| **AI-ready Data Foundation** | **100.0%** | **32.0%** | **2,190百万円** |

## 質問3: 失敗からの学習

**質問**: 成功案件と失注案件を比較し、提案初期に確認すべき条件を整理してください。

### 期待される応答の要件

- [ ] P006（API Modernization失注）とP010（AI Agent Production失注）の両方が参照されている
- [ ] Azure AI Searchから Bid Review文書（DOC-P006-BIDR、DOC-P010-BIDR）が引用されている
- [ ] P006の失注要因（APIオーナー不明確・移行責任分界・非機能要件未確定）が含まれている
- [ ] P010の失注要因（データ権限未整理・評価指標未定義・本番運用責任未確定）が含まれている
- [ ] 成功パターン（受注案件）との比較が含まれている
- [ ] 提案初期確認事項として一般化された形で整理されている

### 期待されるチェックリスト（最低限）

1. APIオーナー・データオーナーの確定
2. 非機能要件・SLAの事前合意
3. 本番運用責任者の確定
4. 評価指標・受け入れ基準の合意
5. 移行期間中の責任分界の明確化
